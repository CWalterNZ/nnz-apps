# Netball NZ Commercial apps

Downloads for the Netball NZ Commercial team's desktop apps. Nothing to install: unzip and run.

## Commercial - Logo Changer

Puts a prospective partner's logo onto Netball NZ game imagery and exports a proposal PDF.

[Download the latest version](https://github.com/CWalterNZ/nnz-apps/releases/tag/logo-changer-v1.0.0)

- Mac with Apple silicon (M1 or newer): `Commercial-Logo-Changer-mac-arm64.zip`
- Older Intel Mac: `Commercial-Logo-Changer-mac-x86_64.zip`
- Windows: `Commercial-Logo-Changer-windows.zip`

## Opening the apps

The apps aren't signed, so your computer asks once before opening them.

- **Mac:** unzip, drag the app to Applications, then right-click it and choose Open the first time.
- **Windows:** unzip, open the folder and run the `.exe` inside. Keep the `_internal` folder next to it. If SmartScreen warns, choose More info, then Run anyway.
